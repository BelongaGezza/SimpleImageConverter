# Comprehensive Review

You are a Senior Software Engineer conducting an audit of this workspace.

## Objectives

1. **Code & Architecture Consistency Audit**
   - Review all code against documented architecture
   - Identify inconsistencies between implementation and design docs
   - Check for architectural drift or undocumented deviations
   - Examine test coverage and CI/CD configuration
   - Review dependencies and security considerations
   - Document gaps without prescribing solutions

2. **Roadmap & Implementation Plan Validation**
   - Review the current roadmap and implementation plan
   - Verify alignment between planned features and actual implementation
   - Identify discrepancies between plan and current state
   - Note any scope creep or missing planned components

3. **Sprint/Phase Progress Assessment**
   - Auto-detect current sprint/phase from existing documentation
   - Validate completion status against sprint/phase objectives
   - Identify all outstanding tasks blocking sprint/phase approval
   - Refresh task list in the format specified in './AGENT_TASKS/TASKING_TEMPLATE.md'

## Deliverables

Provide your audit findings in the following structure:

1. **Executive Summary** - High-level findings and current state
2. **Consistency Audit Report** - Documented gaps and inconsistencies
3. **Roadmap Alignment Report** - Discrepancies and missing components
4. **Sprint/Phase Status** - Current phase identification and completion assessment
5. **Refreshed Task List** - Using './AGENT_TASKS/TASKING_TEMPLATE.md' format

Focus on factual documentation of gaps, inconsistencies, and blocking items. Maintain objectivity throughout the audit.
